# Equal Earth Projection Map

Equal Earth Projection（イコールアース図法）で世界地図を描画し、マウスドラッグで中心経度を連続的に変更できるブラウザアプリです。投影式は外部ライブラリを使わず自前実装しています。

## 概要

- `index.html` を開くだけで動作する単一HTMLファイルのWebアプリです。
- Canvas 2D 上に、簡易化した世界の陸地ポリゴンを Equal Earth Projection で描画します。
- 地図をマウスでドラッグすると、ドラッグ量に応じて中心経度が滑らかに変化し、地図がリアルタイムに再投影・再描画されます。

## 技術的特徴

- **投影式の自前実装**: Equal Earth Projection の数式（Šavrič, Patterson, Jenny, 2018）を外部ライブラリなしで実装しています（`equalEarthRaw` 関数）。
- **requestAnimationFrame による滑らかな描画**: ポインタイベントは状態（中心経度）の更新のみを行い、実際の再描画は `requestAnimationFrame` ループ内で「更新が必要なときだけ」実行することで、カクつきのないスムーズな操作感を実現しています。
- **ダテライン（対蹠経線）分割による描画破綻の防止**: 中心経度を変えると陸地ポリゴンが画面の裏側（中心+180°）をまたぐことがありますが、まわり込む頂点間を新しいサブパスとして分割することで、帯状に伸びる描画崩れを防いでいます。
- **外部データフェッチなし**: 簡易化した世界の陸地ポリゴンをコード内にハードコードしており、オフラインでも完全に動作します。
- **テスト容易性のための構成**: 投影計算のコア関数は `src/equalEarth.js` に純粋関数として切り出し、Vitest によるユニットテストで検証しています（`index.html` にも同一実装をインライン化し、単一ファイルでの配布要件を満たしています）。

## 依存ライブラリとインストール手順

アプリ本体（`index.html`）は依存ライブラリを一切使用しません。ブラウザで直接開くだけで動作します。

ユニットテストを実行する場合のみ、Node.js と npm、および開発依存の Vitest が必要です。

```bash
git clone https://github.com/himayah/equal-earth-projection.git
cd equal-earth-projection
npm install
```

## 起動方法

以下のいずれかの方法で `index.html` を開いてください。

### 方法A: ファイルを直接ブラウザで開く

`index.html` をブラウザにドラッグ＆ドロップするか、ブラウザから `file://` パスで直接開きます。

### 方法B: 簡易HTTPサーバ経由で開く（推奨）

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/index.html` を開きます。

## 使用方法

1. ブラウザで `index.html` を開くと、中心経度0°の世界地図が表示されます。
2. 地図上でマウスをドラッグ（左ボタンを押したまま左右に動かす）すると、ドラッグ量に応じて中心経度が連続的に変化し、地図が滑らかに再投影されます。
3. 画面左下に現在の中心経度が表示されます。
4. ウィンドウサイズを変更すると、地図は自動的にリサイズされます。

## 終了方法

通常のWebページと同様に、ブラウザのタブ／ウィンドウを閉じるだけで終了します。バックグラウンドプロセスやサーバーの明示的な停止は不要です（方法Bで簡易HTTPサーバーを使った場合は、ターミナルで `Ctrl+C` を押してサーバーを停止してください）。

## テストの実行方法

```bash
npm test
```

`src/equalEarth.js` に定義した投影計算・座標変換・ドラッグ量変換の各関数を Vitest でユニットテストします。

## 使用上の注意点

- 地図データは学習・デモ用に大幅に簡易化した陸地ポリゴンです。正確な地理情報や測量用途には使用できません。
- 極（北極・南極）付近は Equal Earth Projection（擬円筒図法）の性質上、他の地域より歪みが大きくなります。また、ドラッグの感度は赤道上の投影スケールを基準にしているため、極付近でのドラッグ操作の見た目の速さはやや不自然になる場合があります。
- マウス操作（ドラッグ）を前提として作成しており、タッチ操作（スマートフォン・タブレット）は動作対象外です。
- モダンブラウザ（Chrome / Edge / Firefox の最新版）での動作を想定しています。
