# Equal Earth Projection Map

Equal Earth Projection（イコールアース図法）で世界地図を描画し、マウスドラッグで中心経度を連続的に変更できるブラウザアプリです。投影式は外部ライブラリを使わず自前実装しています。

## 概要

- `index.html` を開くだけで動作する単一HTMLファイルのWebアプリです。
- 起動時に Natural Earth 10m land データ（CC0、詳細は後述）を `fetch()` で取得し、Canvas 2D 上に Equal Earth Projection で描画します。
- 地図をマウスでドラッグすると、ドラッグ量に応じて中心経度が滑らかに変化し、地図がリアルタイムに再投影・再描画されます。

## 技術的特徴

- **投影式の自前実装**: Equal Earth Projection の数式（Šavrič, Patterson, Jenny, 2018）を外部ライブラリなしで実装しています（`equalEarthRaw` 関数）。
- **requestAnimationFrame による滑らかな描画**: ポインタイベントは状態（中心経度）の更新のみを行い、実際の再描画は `requestAnimationFrame` ループ内で「更新が必要なときだけ」実行することで、スムーズな操作感を実現しています。
- **地図境界での正しい部分表示**: ドラッグで中心経度を変えると陸地ポリゴンが画面の境界（中心の対蹠側、中心+180°）をまたぐことがあります。各陸地ポリゴンを中心経度に依存しない連続した経度表現にあらかじめ変換しておき（`unwrapRingLongitudes`）、必要な360°オフセット分だけ複製したうえで、投影前にパラメータ空間上で表示範囲 `[-180°,180°]` へ明示的にクリップします（`clipRingToLongitudeWindow`）。Equal Earth Projectionはx方向のスケールが緯度によって変化するため、「表示範囲外はCanvasが自然にクリップする」という単純な前提は成り立たず、明示的なクリップが必須であることが実機検証で判明しました。これにより、大陸の一部が表示範囲外に出ても、表示範囲内の部分は地図本来の輪郭曲線に沿って正確に部分表示され続け、特定の中心経度でだけ描画が乱れることもありません（詳細は [docs/設計書.md](./docs/設計書.md) 8章）。
- **外部データの fetch**: 世界の陸地ポリゴンは Natural Earth 10m land データ（CC0、約41万座標点）を `fetch()` で取得して描画します。データ自体は外部ライブラリではなく、標準の `fetch()` API のみを使用しています。
- **テスト容易性のための構成**: 投影計算・GeoJSON展開のコア関数は `src/equalEarth.js` / `src/geojson.js` に純粋関数として切り出し、Vitest によるユニットテストで検証しています（`index.html` にも同一実装をインライン化し、単一ファイルでの配布要件を満たしています）。

## 地図データについて

- 出典: [Natural Earth](https://www.naturalearthdata.com/) 10m land（`martynafford/natural-earth-geojson` リポジトリ経由のGeoJSON変換版）
- ライセンス: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)（パブリックドメイン）
- 取得元URL: `https://raw.githubusercontent.com/martynafford/natural-earth-geojson/master/10m/physical/ne_10m_land.json`

## 依存ライブラリとインストール手順

アプリ本体（`index.html`）はビルドや外部ライブラリを一切使用しません。ただし起動時に上記の地図データをネットワーク経由で取得するため、**インターネット接続が必要**です。

ユニットテストを実行する場合のみ、Node.js と npm、および開発依存の Vitest が必要です。

```bash
git clone https://github.com/himayah/equal-earth-projection.git
cd equal-earth-projection
npm install
```

## 起動方法

**`file://` で直接開くと、ブラウザのセキュリティ制限により地図データの `fetch()` が失敗することがあります。必ずローカルHTTPサーバ経由で開いてください。**

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/index.html` を開きます（Node.js環境であれば `npx serve` 等でも代用できます）。

## 使用方法

1. ブラウザで `index.html` を開くと、「地図データを読み込み中…」と表示された後、中心経度0°の世界地図が表示されます（地図データは約18MBあり、回線速度によっては表示まで数秒〜十数秒かかる場合があります）。
2. 地図上でマウスをドラッグ（左ボタンを押したまま左右に動かす）すると、ドラッグ量に応じて中心経度が連続的に変化し、地図が滑らかに再投影されます。
3. 画面左下に現在の中心経度が表示されます。
4. ウィンドウサイズを変更すると、地図は自動的にリサイズされます。
5. 地図データの取得に失敗した場合（ネットワーク未接続など）は、画面中央にエラーメッセージが表示されます。ページを再読み込みして再試行してください。

## 終了方法

通常のWebページと同様に、ブラウザのタブ／ウィンドウを閉じるだけで終了します。ローカルHTTPサーバを起動した場合は、ターミナルで `Ctrl+C` を押してサーバーを停止してください。

## テストの実行方法

```bash
npm test
```

`src/equalEarth.js`（投影計算・座標変換・経度の連続化・表示オフセット判定・パラメータ空間でのクリッピング・ドラッグ量変換）と `src/geojson.js`（GeoJSONからのリング抽出）の各関数を Vitest でユニットテストします。

## 使用上の注意点

- 初回表示にはインターネット接続が必須です。オフラインでは地図データを取得できず、エラー表示になります。
- 地図データは約41万座標点と大きいため、非常に低スペックな端末やネットワーク環境では、初期読み込みやドラッグ中の描画がやや重くなる場合があります（手元の検証環境では、ドラッグ中も平均36fps前後で描画できることを確認しています）。
- Antarctica（南極大陸）は経度を一周する特殊な形状のため、ごくまれに縫い目付近で描画上の軽微な不整合が生じる可能性があります（詳細は [docs/設計書.md](./docs/設計書.md) 8.4章）。
- 極（北極・南極）付近は Equal Earth Projection（擬円筒図法）の性質上、他の地域より歪みが大きくなります。また、ドラッグの感度は赤道上の投影スケールを基準にしているため、極付近でのドラッグ操作の見た目の速さはやや不自然になる場合があります。
- マウス操作（ドラッグ）を前提として作成しており、タッチ操作（スマートフォン・タブレット）は動作対象外です。
- モダンブラウザ（Chrome / Edge / Firefox の最新版）での動作を想定しています。
